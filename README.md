# X投稿キーワード通知（Yahooリアルタイム検索版）

Yahoo!リアルタイム検索の非公式API（`https://search.yahoo.co.jp/realtime/api/v1/pagination`）を利用して、
指定したXアカウントの投稿に特定キーワードが含まれたらデスクトップ通知するChrome拡張機能です。

## 導入方法

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`x-keyword-notifier`）を選択

## 使い方

1. 拡張機能アイコンをクリックしてポップアップを開く
2. 「監視するXアカウント」に `@` なしのユーザー名（例: `nhk_news`）を入力
3. 「通知するキーワード」にキーワードを入力
4. チェック間隔（分）を設定（デフォルト5分、最小1分）
5. 「監視開始」をクリック

以降、バックグラウンドで `chrome.alarms` により定期的にAPIを叩き、
新着投稿にキーワードがヒットするとデスクトップ通知が出ます。通知をクリックすると該当ポストをXで開きます。

「今すぐチェック」で即座に1回だけチェックできます。

## 検索クエリの仕組み

`ID:アカウント名 キーワード` というAND検索クエリをAPIに投げています（調査メモに基づく仕様）。
例: `ID:nhk_news 速報`

新着順（`md` パラメータ省略）で取得し、`entry[].id` を前回チェック時と比較することで
「前回チェック以降に増えたエントリ」のみを新着として通知します。
初回起動時は過去分をまとめて通知しないよう、基準点の記録のみ行います。

## 制限・注意点（調査メモより）

- **認証不要**ですが、一般的なブラウザのUser-Agentでないとブロックされる場合があります（本拡張はブラウザから直接fetchするため通常は問題になりにくいですが、うまく取得できない場合はご留意ください）。
- 日本語ツイート中心のインデックスのため、**海外ユーザーの投稿はほぼ拾えません**。
- レート制限は確認された範囲では見つかっていませんが、あくまで非公式APIなので**仕様変更やアクセス遮断のリスク**があります。
- `results` は最大40件までです。
- `since` / `until` はUnixタイムスタンプのみ有効です（本拡張では未使用）。

## ファイル構成

- `manifest.json` — 拡張機能の定義（Manifest V3）
- `background.js` — 定期チェック・API呼び出し・通知処理（Service Worker）
- `popup.html` / `popup.js` — 設定用UI
